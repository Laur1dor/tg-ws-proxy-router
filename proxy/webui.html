Вход в управление

Логин и пароль выдаются командой tgws web init. Сброс: tgws web reset-password.

Проверяем состояние

Изменения сохраняются в общий конфиг TGWS. Консольная TUI-панель остаётся доступна. Не редактируй настройки одновременно в двух панелях.

Cloudflare Worker

Cloudflare должен быть доступен со стороны TGWS. Звонки используют свои маршруты.

Маршруты

Имена выходов через запятую, в порядке переключения при сбое. Пароли выходов редактируются в TUI или конфиге.

Применение

Сохранение создаёт резервную копию. Перезапускается только TGWS; активные подключения к этому прокси могут прерваться.

Ссылки подключения

Для родственников укажи внешний адрес домашнего прокси. Для локальных устройств — адрес в LAN. Ссылки содержат секреты: передавай их только своим пользователям.
